# EduPlatform — Платформа онлайн-курсов

Тренировочный веб-сайт на Django для управления онлайн-курсами, преподавателями, студентами и прогрессом обучения.

## Использованные технологии
- **Python 3.14+**
- **Django 6.1+**
- **SQLite** (встроенная база данных)

## Архитектура проекта (основные модели)
- `Instructor` — преподаватели с рейтингом и специализацией.
- `Category` — дерево категорий и подкатегорий курсов (self-ссылка).
- `Course` — курсы с автоподсчетом свободных мест и среднего рейтинга.
- `Student` — профили студентов.
- `Enrollment` — связь многие-ко-многим между студентами и курсами с фиксацией прогресса (`%`) и итоговой оценки.
- `Lesson` — уроки, привязанные к курсам.
- `Review` — отзывы студентов на курсы.

## Инструкция по локальному запуску

### 1. Клонирование проекта и переход в папку
```bash
cd PythonProject011026
```

### 2. Активация виртуального окружения
* **Windows**:
  ```bash
  .venv\Scripts\activate
  ```
### 3. Применение миграций базы данных
Создание структуры таблиц в SQLite:
```bash
python manage.py migrate
```

### 4. Создание суперпользователя для админки
Для управления контентом создайте аккаунт администратора:
```bash
python manage.py createsuperuser
```

### 5. Запуск локального сервера
```bash
python manage.py runserver
```

После этого проект будет доступен в браузере по адресам:
- Главная страница: [http://127.0.0](http://127.0.0)
- Панель администратора Django: (http://127.0.0.1:8000/admin)

## Кастомные методы и менеджеры (внутри кода)
В файле `library/queries.py` реализованы ORM-запросы для агрегации статистики студентов, преподавателей и фильтрации популярных/активных курсов.
